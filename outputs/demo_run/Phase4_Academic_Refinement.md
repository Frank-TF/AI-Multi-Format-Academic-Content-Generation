## 1. Executive Abstract

The Internet of Things (IoT) constitutes a paradigm shift in distributed computing, acting as a bidirectional bridge between cyberspace and the physical environment [1]. Between 2010 and 2020, the share of IoT devices among all connected devices rose from 10% to more than 50%, while the installed base reached approximately 10 billion units; IoT therefore crossed the tipping point at which connected things outnumber conventional Internet nodes [1]. This expansion is enabled by the cloud-edge-thing continuum, in which constrained sensing nodes, local gateways and central data centres cooperate to deliver real-time monitoring and actuation [1], [2]. The same architecture, however, exposes critical limitations. Low-end devices operate with microWatt energy budgets, kilobytes of memory and low-bandwidth links, which invalidate conventional security and programming models [1], [5]. Pervasive sensing also creates privacy, surveillance and digital-sovereignty risks that cannot be resolved by technical means alone [1], [6]. This report synthesises the Inria evidence base into four artefacts: a structured study guide, a ten-slide academic deck, an A4 infographic and a refined scholarly text. Across these formats, the analysis shows that lightweight cryptography, federated learning, signed firmware updates and open standards are necessary but insufficient without legal accountability and public trust. The central conclusion is that secure-by-design engineering and digital sovereignty must be treated as preconditions for sustainable IoT adoption, not as optional post-deployment features.

## 2. Glossary of Key Academic Terms

1. **Cyber-Physical Systems (CPS):** Integrated systems in which computational algorithms monitor and control physical processes through sensor-actuator loops.
2. **Edge Computing:** A distributed computing model that places computation and storage close to data sources to reduce latency and core-network traffic.
3. **Lightweight Cryptography:** Cryptographic primitives optimised to run securely within the energy, memory and CPU limits of constrained hardware.
4. **Federated Learning (FL):** A decentralised machine-learning method in which nodes train a shared model locally and exchange model updates rather than raw data.
5. **Digital Sovereignty:** The ability of individuals or states to retain control over their digital infrastructure, data and technology supply chain.
6. **Web of Things (WoT):** An application-layer approach that describes and exposes things using web standards such as URIs, HTTP and JSON-LD.
7. **Intermittent Computing:** A computing model for battery-less, energy-harvesting nodes that preserves state across frequent power failures using non-volatile memory.
8. **Object Security (OSCORE):** End-to-end protection applied to the application-layer payload rather than relying only on the transport channel.
9. **SUIT:** A standardised manifest format for secure firmware updates on constrained IoT devices.
10. **Surveillance Capitalism:** An economic model built on harvesting, processing and monetising behavioural data captured by pervasive sensors and trackers.
11. **Smart Dust:** Millimetre-scale or smaller motes that can sense, compute and communicate without a conventional circuit board.
12. **Dual Prediction Minimisation:** An energy-saving technique in which node and edge run matching predictors and transmit only when a measurement deviates.
